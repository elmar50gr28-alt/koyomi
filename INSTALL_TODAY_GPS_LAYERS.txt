KOYOMI「今日の暦」本人・GPS連動レイヤー

導入方法
1. ZIPを展開します。
2. ZIP内のファイルを、koyomiリポジトリの同じ場所へ上書きします。
3. GitHubで Commit changes を押します。
4. 公開後、ブラウザを一度再読み込みします。

使い方
- app.html の「鑑定人物台帳」で本人にチェックを付け、生年月日を保存します。
- today.html の「宿曜・星」を押すと、本人の本命宿・太陽星座と今日の宿・曜日星を表示します。
- 「奇門遁甲」を押すと位置情報の許可を確認し、現在地・時辰・真太陽時を表示します。
- GPS座標は端末内だけで処理し、app.html の運命航法盤へ引き継ぎます。

注意
- 人物台帳が暗号化ロック中の場合、today.htmlからは本人情報を読みません。app.htmlで解除してください。
- GPSを拒否した場合は、app.html#qimen で地点を手入力できます。
- 九宮盤の本計算は既存の app.html の奇門遁甲エンジンを使用します。
