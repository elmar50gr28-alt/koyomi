# KOYOMI Release Plan

最終更新: 2026-08-05

## Internal Prototype

目的: 起動、保存、基本導線、PWA配信を確認する。
品質条件: JavaScriptエラーなし、主要ページ表示、Service Worker更新、端末内保存。
対象: 開発者内部。

## Alpha

目的: 統合プロフィールと主要占術の最小導線を確認する。
品質条件: 本人登録、再編集、自動保存、iPhone入力、回帰テスト。
対象: 限定内部テスター。

## Bazi Beta

目的: 四柱推命を本鑑定ベータとして運用する。
品質条件: 総合結論、テーマ別鑑定、根拠、流派差、初心者/専門家表示、日本語表示、健康表現の安全性。
対象: 四柱推命レビュー協力者。

## Release Candidate

目的: 複数占術を統合し、一般公開前の品質を固める。
品質条件: 主要占術の根拠、命例、回帰テスト、モバイルUX、オフライン、プライバシー表示。
対象: 外部テスター。

## Version 1.0

目的: 個人向けKOYOMIとして正式公開する。
品質条件: 初回だけプロフィール入力、本人自動選択、総合鑑定、今日のナビ、PWA安定、利用規約/プライバシー。
対象: 一般利用者。

## App Store Beta

目的: ネイティブアプリ化の技術検証を行う。
品質条件: 端末内保存、通知、オフライン、iPhone UI、審査対応。
対象: TestFlightテスター。

## Public Release

目的: 安定版を広く公開する。
品質条件: サポート導線、バックアップ、障害対応、法的表示、更新方針。
対象: 一般公開。

## Professional Edition

目的: 占い師、店舗、イベント向けの業務機能を提供する。
品質条件: 顧客管理、カルテ、鑑定履歴、タグ、CSV、プロ表示、権限、バックアップ。
対象: プロ利用者。

## KOYOMI Engine API

目的: 計算、根拠、説明層を外部利用可能にする。
品質条件: 個人情報分離、API契約、バージョン管理、レート制限、ライセンス、監査ログ。
対象: 外部サービス、研究、業務提携。
