# 個別銘柄ページの経済カレンダー

- 対象：日本の主要統計（e-Stat掲載分）、米国BEAの公式発表予定。
- 日本は物価、雇用、賃金、家計、鉱工業、貿易、GDP等の統計名を選別。日付が確定している予定だけを収録。月末・上旬などの概算日は確定日に置換しない。
- 米国はBEA公式ICSからGDP・個人所得/個人消費支出・貿易等を収録。UTCからJSTへ変換するため、夏時間・年越しも反映する。原文も表示する。
- BLS（米雇用統計・米CPI等）、日銀、FOMCは公式ページへのリンク。今回の一覧には自動収録しない。BLSの自動取得は提供元で拒否されたため、制限の回避は行っていない。
- 発表対象期間・速報/確報などは公式タイトルに含まれる情報を表示する。市場予想・前回・結果値・重要度は取得しない。結果は出典先で確認する。
- 鑑定基準日から7/30/90日（当日を含む）を絞り込み。占いの90日間の区間は既存どおり翌日からで、経済カレンダーの期間を明示する。
- 予定時刻を過ぎても発表済みと断定しない。銘柄固有情報や占い計算には渡さない。

## 取得・更新

`node scripts/update-economic-calendar.mjs`

日本は当月から4か月分、米国は公式カレンダーに掲載された将来の予定を取得する。データは `data/financial/economic-calendar.json`。取得失敗した出典は従前データ・元の確認時刻を保持し `error` とする。初回取得失敗ではファイルを作らない。

GitHub Actions は毎日06:15 JSTと手動で更新用PRを作成する。自動マージしない。更新はレビュー・マージ・公開後にアプリへ反映される。リポジトリ設定でActionsからのPR作成が許可されている必要がある。

画面の確認ボタンは公開済みの最新スナップショットを確認する。公式サイトへのリアルタイム問い合わせではない。最終確認から3日超または出典取得エラー時は注意を表示する。収録期間外は「予定なし」と断定しない。日程変更時は公式サイトを優先する。

## オフライン

モジュール・JSONをアプリシェルに同梱。JSONはネットワーク優先、失敗時は保存済み応答を利用する。ページ側も検証済みJSONを端末に保存し、通信失敗時に復元する。古い応答で新しい保存データを上書きしない。
