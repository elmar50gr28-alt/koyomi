# 地震研究の異常値強調表示

## 表示の意味

地震研究レイヤーの「変化」でのみ、研究条件を満たしたセルを暗色の縁取り付き太枠で表示する。従来のセル塗り、予測計算、release gate、保存データは変更しない。

- 白：比較可能な平常比が95以上（地震発生確率95%ではない）。
- 黄：急静穏化が反応ありで、相対指標が正の値。
- 桃：熱異常モデルが候補ありで、温度上昇側の証拠値が正の値。
- 水色：熱異常モデルが候補ありで、温度低下側の証拠値が正の値。

複数候補の枠色は熱上昇、熱低下、急静穏化、平常比の順で優先する。選択したセルの先頭カードにはすべての該当種類と相対指標の最大値を表示する。未取得、更新停止、履歴・周辺観測不足、非有限値、範囲外値は強調対象にしない。枠なしは安全を意味しない。全球共通の地磁気を地域固有の異常として強調しない。

## 解像度と切替

平常比・急静穏化の枠は計算元セルを直接描画し、縮小時の中央値に異常を埋没させない。熱の枠は観測元セルにまとめ、拡大による子セルへの継承を高精細な実観測と誤認させない。選択地域の候補件数も熱観測元で重複排除する。

OFF、現在値、実績では異常枠を空にし、他テーマではレイヤーを非表示にする。日時・対象規模・期間を変更した場合、以前の条件の異常値カードを隠す。新規モジュールはオフライン用シェルにも収録する。

## 検証

- `tests/earthquake-anomaly-presentation.test.mjs`：固定条件、欠測・範囲外値、計算・観測解像度、重複排除、描画更新、表示接続、オフライン依存。
- `npm test`：既存AT01〜AT10を含む全回帰。
- `npm run test:static` / `npm run test:mobile`。
- ローカルブラウザー：通常格子との太枠の差、セル選択時の先頭カード、390×844の表示幅、現在値への切替で枠・見出しが消えることを確認。

熱異常は研究候補であり、地震発生確率への寄与は引き続き0。実ホールドアウトは実行しない。
