# 地震予測検証基盤・熱移送仮説研究レイヤー

この機能は、KOYOMI World に表示する地震研究値を、発行時点の条件のまま保存して事後評価するための研究基盤です。科学的に確立した地震予知、発生確率、防災情報ではありません。防災判断では公的機関の情報を優先します。

## 分離原則

- 地震活動モデル、震源深度移動、熱移送仮説、マンデン占術は別の値として保存します。
- マンデン占術と熱研究指標を地震活動モデルの確率へ直接加算しません。
- NASA FIRMS は火災、火山、固定熱源などの除外・分類だけに使い、地震前兆の直接観測として扱いません。
- 欠測、古い観測、標本不足、未接続はゼロへ変換せず `insufficient-data` または `data-unavailable` とします。
- 地表温度の実データ取得元は未確定です。現在はスキーマ、アダプター、集約スクリプト、テスト用 fixture だけを提供し、本番UIには「地表温度データ未接続」と表示します。

## 主な構成

- `depth-migration.js`: USGSカタログから深度中央値、深度帯構成、期間前後差、震源重心、隣接格子移動を計算します。最低件数未満では方向・強度を返しません。
- `thermal-source-exclusions.js`: FIRMS相当の観測を火災候補、活火山、固定・工業熱源、低信頼、古い観測、複数衛星確認、原因不明へ分類します。第1段階では全件を確率入力から除外します。
- `surface-temperature-adapter.js`: 将来の地表温度格子データを検証し、選択日時以後の観測を遮断します。
- `thermal-transfer-hypothesis.js`: 地質背景、震源深度移動、地表熱偏差、継続性、熱源除外、品質、空間・時間一致を独立要素として扱います。必須要素が欠ける場合、総合一致度は返しません。
- `prediction-schema.js` / `prediction-ledger.js`: SHA-256付きの変更不能な発行記録と、別追記の評価記録を端末へ保存します。
- `prediction-evaluation.js`: 固定した格子、隣接格子、期間、規模、深度で照合し、連続予測をエピソード化します。同一地震を複数エピソードの的中へ無制限に割り当てません。
- `research-validation-ui.js`: 「現在の見立て」「予測記録」「検証成績」の3タブを提供します。地球儀は地域選択の入口のまま維持します。

## 時刻と改変防止

前向き予測では、対象期間は実際の発行時刻より前に開始できません。過去日を選んだ計算は `retrospective-replay` として、実発行時刻と計算基準時刻を別に保存します。再現計算は計算基準時刻より未来のデータを利用できず、前向き検証成績へ混ぜません。発行済み予測の修正は上書きではなく、新しい予測IDで行います。

## 評価

同じ行・期間・対象条件について、長期背景、最近の地震活動、震源深度移動を含むモデル、熱研究指標を含むモデルを比較できる契約です。Brierスコア、Log Loss、Information Gain、捕捉率、エピソード的中率、空振り率、見逃し率、時空間警戒率、警戒日率、先行日数、上位地域捕捉率、校正階級を返します。未固定モデルや未接続データの値は作らず、`判定不能` と表示します。

## 地表温度データ受け入れ

`scripts/aggregate-surface-temperature-grid.mjs` は、出典と製品版が確認済みの入力だけを軽量格子JSONへ集約します。既存出力を上書きしない `wx` モードです。生の衛星画像や世界全体の日次データをブラウザへ配信しません。fixture は `tests/fixtures/` 配下に限定し、本番値として表示しません。
