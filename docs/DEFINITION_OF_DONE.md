# KOYOMI Definition of Done

最終更新: 2026-08-05

## 共通完了条件

- 仕様が文書化されている。
- 影響範囲が説明されている。
- 既存機能、既存占術、既存データを壊していない。
- 未知フィールドを削除していない。
- 人物情報の重複入力を増やしていない。
- 決定論的計算とAI説明を分離している。
- 根拠、sourceIds、schoolIds、confidence、reviewStatusを保持している。
- 一般表示と専門家表示が分離されている。
- 一般表示に内部IDや英語コードを出していない。
- 日本語UIでは自然な日本語で表示される。
- iPhone Safari相当の表示・入力を確認している。
- 静的検証と該当テストが成功している。
- Service Worker対象に必要ファイルが含まれている。
- commit、push、PRまたはCompare URLがある。
- GitHub Actionsが成功している。
- mainへのmergeは人間承認後に行う。

## 占術エンジンの完了条件

- 入力スキーマがある。
- 出力スキーマがある。
- 計算ロジックが決定論的である。
- 根拠DBがある。
- 古典原文、要約、現代解釈が分離されている。
- 流派差を保持している。
- 反対説または未確定要素を表現できる。
- 命例または代表ケースがある。
- 回帰テストがある。
- 初心者向け説明と専門家向け根拠表示がある。

## UIの完了条件

- 1画面1目的。
- 主要操作が親指範囲にある。
- タップ領域が44px相当以上。
- 横スクロールがない。
- 入力中に下部ナビゲーションが隠れる。
- キーボードで入力欄や主要ボタンが隠れない。
- 100vh依存を避けている。
- safe-area-insetに対応している。

## ドキュメントの完了条件

- 文字化けしていない。
- 正本と参照先が明確。
- 最新日付、対象ブランチ、状態分類がある。
- 未実装を未実装として記録している。
- 次タスクが明確。
