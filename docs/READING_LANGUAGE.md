# 鑑定文の生活表現と語りかけ

## 2026-10-09

占術別の文章は、計算に基づく読み解き、生活での活かし方、自分を大切にする語りかけを段落で分ける。仕事・人間関係・お金・健康・日常の各分野に三つの場面を用意し、後押し／確認／負担の抑制に応じて内容を変える。

日付で切り替わるのは読みの活用例であり、新しい予言ではない。同じ材料なら根拠・中心の読み解きは維持する。生活場面は条件付きで示し、自由文から分からない事情や感情、努力、相手の本心を断定しない。語彙を機械的な同義語で置換しない。

タロット・ルーンでは象徴から導いた助言を維持する。明示された行動、低確度、安全リスク、必要な受診については従来の保護を優先する。新しい文章のために外部通信や生成AIを追加しない。

本鑑定の日次文章も、説明・生活場面・語りかけを分ける。主テーマ、行動、強度、履歴による重複抑制の選択は変更しない。

検証：五分野×三方向×30日×両口調の900表示で、同じ根拠と中心の読み解きを保ち、活用例を含む本文は各30種類になることを確認。既存の11占術・30日検証、実際のローカル展開、日次鑑定・安全・互換性の検証も実施する。文章が異なることと、占術結果が異なることを区別して評価する。

### 象徴と生活の助言の接続

タロットの「自分の立場」、ルーンの「次の一手」にある既存の解釈語から、停止・刷新・境界・選択・始まり・育成を読み分ける。位置が欠けている場合に、障害や別の位置で穴埋めしない。始まりの象徴でも、障害や最終結果に注意があれば、活用例は確認を優先する。停滞・内省を含む既存の反転解釈では、開始を急がせない。

休む読みと区切る読みには、それぞれ10種類の語りかけを用意する。区切りの行動は本人が変えたい場合の確認として表現し、別離・退職・契約終了を象徴だけで決めない。お守りのテーマも同じ解釈に合わせる。既存の「月と皇帝」などの個別読み解きと、明示した行動は維持する。

追加検証：六つの象徴の意味×五分野×30日×両口調の1,800表示、混在する展開、反転解釈、欠けた位置、休む／区切る助言の違い、お守りとの整合性を確認する。

### 数秘と宿曜の持ち味

アプリの既存辞書にある個人年12種類と、選択日の距離7種類を、見出し・生活への読み解き・三つの助言に結びつける。数秘は周期数と既存の解釈文が一致した場合だけ固有の読みを使い、未知の解釈や食い違う入力には一般の読みを残す。宿曜も辞書と一致する距離の解釈だけを使う。

一年のテーマを今日だけの吉凶に置き換えず、選択日との距離を相手との相性や相手の意思として語らない。積み重ね・表現・調整・完了などの違いを、本人が選べる形の助言へつなげる。健康分野では必要な受診の助言を優先する。

実際の相談メニューの転職・買い物・収入・結婚・家族なども、対応する生活場面へそろえる。検証は19種類×五分野×30日×両口調の5,700表示。日付で根拠や中心のテーマを変えないこと、30種類の活用文章と三つの助言、未知の入力への代替表示、相談項目と生活場面の一致を確認する。

### 姓名と本命星の読み解き

九星の計算表示 `1紫白`〜`9紫白` を、既存の `一白水星`〜`九紫火星` の解釈辞書へ接続する。以前の表示名による直接参照では解釈を取得できなかったため、表示の対応だけを修正する。占術の計算や点数は変更しない。不明なラベルや不完全な辞書は空の解釈へ戻し、補完しない。

本命星9種類、姓名の既存解釈10種類を、固有の見出しと助言へつなげる。姓名では画数と解釈の一致を確認し、人格・地格・外格・総格の位置の意味を添える。同じ解釈が重なる場合は、すべての根拠を残しながら説明をまとめる。生まれた年や名前から日々の出来事・性格を決めつけない。

追加検証は19種類×三分野×30日×両口調の3,420表示。実際の本鑑定の解釈入力式、9種類の表示名と辞書の対応、姓名の四つの位置・同じ解釈の重複、未知／食い違う解釈への代替表示、仕事の相談に無関係な出費の助言が混じらないことを確認する。
