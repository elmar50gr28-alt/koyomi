# KOYOMI Epics

最終更新: 2026-08-05

GitHub Issuesで管理するためのEpic候補です。Issue作成権限がない場合、このファイルをIssue本文の正本として扱います。

## EPIC-001 統合人物プロフィール

目的: personIdで本人、家族・友人、プロ顧客を一元管理し、全占術で重複入力をなくす。
状態: 部分実装。
子Issue候補: 本人再編集、重複防止、世界名、出生地検索、家族・友人導線、プロ顧客導線。
完了条件: 初回本人登録、二回目以降自動選択、自動保存、未知フィールド保持、既存データ互換。
依存: PWA保存、プロフィールスキーマ、モバイル入力UX。
