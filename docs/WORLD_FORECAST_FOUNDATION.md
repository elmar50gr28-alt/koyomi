# 共通世情予測基盤 v0.2 技術記録

## 実装範囲

初版は共通入力・共通結果、占術Adapter、空間provider、マンデン地震テーマの説明可能な寄与表示、スマートフォン地図、Future/Validationの分離を追加した。異なる占術の数値は加算せず、閾値以上の系統数を表示する。

マンデン地震Adapterは既存の天体位置と地域ASC/MC計算だけを再利用する。外惑星・火星の主要ハード角、地域四大角、新月・満月付近の3寄与を研究用に表示する。食、ノード、地域チャートの歴史的ルール、長期周期は未実装であり、科学的な発生確率ではない。ルール版は `mundane-earthquake-v0.1-experimental` とする。

## 空間方式

H3 4.5.0を正式providerとして採用した。バンドラーのない静的PWAでもオフライン計算を維持するため、公式ブラウザES module bundle、LICENSE、NOTICEを`vendor/h3-js/4.5.0/`へ固定した。CDNからH3を読み込まない。保存・計算結果は`gridSystemId`、`gridVersion`、`resolution`を持ち、将来の移行時に異なるセル体系を混同しない。

H3も完全等面積ではない。位置、正二十面体頂点との関係、12個の五角形セルにより面積差がある。暫定の`koyomi-equal-area-band`は移行・障害切り分け用に残すが既定providerにはしない。

計算解像度と描画解像度を分離し、zoomに応じてH3 resolution 1〜5を選ぶ。viewportを`polygonToCells`で被覆し、表示は最大500セルとする。上限へ達した場合は描画resolutionを自動的に下げる。更新は`moveend`後にdebounceし、日時・セル・grid版・Adapter版を含むキーで最大2,000結果をメモ化する。

## 地図方式

MapLibre GL JSをWebGL描画層として採用した。現在は公式デモの詳細ベクタースタイルをオンライン取得する。読み込めない場合も共通計算、既存四季図、保存済み研究結果は動作する。MapLibre実行ファイル、スタイル、ベクタータイルのローカル配布とライセンス表記を整えるまで、地図そのものの完全オフライン対応は未完成である。

## Validation

東北、熊本、能登の事象を`data/world/validation-events.json`へ分離し、日時・震源・magnitude・depth・USGS参照先を保持する。地図には実震源マーカーを表示し、選択セルとの同一セル判定、5段階までの近傍ring、セル中心距離を独立表示する。これらは的中判定ではない。対照日・対照地域、破壊域、USGS/JMA更新同期は次段階であり、既存の統計研究資産は保持する。
