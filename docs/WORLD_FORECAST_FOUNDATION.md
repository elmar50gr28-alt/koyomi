# 共通世情予測基盤 v0.1 技術記録

## 実装範囲

初版は共通入力・共通結果、占術Adapter、空間provider、マンデン地震テーマの説明可能な寄与表示、スマートフォン地図、Future/Validationの分離を追加した。異なる占術の数値は加算せず、閾値以上の系統数を表示する。

マンデン地震Adapterは既存の天体位置と地域ASC/MC計算だけを再利用する。外惑星・火星の主要ハード角、地域四大角、新月・満月付近の3寄与を研究用に表示する。食、ノード、地域チャートの歴史的ルール、長期周期は未実装であり、科学的な発生確率ではない。ルール版は `mundane-earthquake-v0.1-experimental` とする。

## 空間方式

H3を第一候補として検討した。H3は階層セルID、セル境界、MapLibreのGeoJSON連携に適する。一方、現リポジトリはバンドラーのない静的PWAであり、H3本体をCDNだけに置くとオフライン計算要件を失う。この差分ではH3を未導入とし、同じprovider APIの後ろに `koyomi-equal-area-band-v1` を実装した。

このフォールバックは緯度を `sin(latitude)` で区切るため、球面上の帯面積を揃えやすい。完全等面積ではない。極域、列数の整数化、地球楕円体との差、セル形状の異方性が例外である。通常の緯度経度矩形グリッドを空間比較の正本にはしない。次段階でH3をローカル配布物として固定し、同一テスト契約へ接続する。

計算解像度と描画解像度を分離し、現在はズームから解像度を選び、viewportを標本化して画面内セルだけをGeoJSON化する。世界中の高解像度セルは生成しない。

## 地図方式

MapLibre GL JSをWebGL描画層として採用した。現在は公式デモの詳細ベクタースタイルをオンライン取得する。読み込めない場合も共通計算、既存四季図、保存済み研究結果は動作する。MapLibre実行ファイル、スタイル、ベクタータイルのローカル配布とライセンス表記を整えるまで、地図そのものの完全オフライン対応は未完成である。

## Validation

初版は東北、熊本、能登の固定事象を選択し、発生日時・震源位置へ地図を移動して当時の実験結果を表示する。実震源マーカー、空間距離、対照日・対照地域、USGS/JMAの更新同期は次段階。既存の統計研究資産は削除せず、同じ社会運画面の研究領域に保持する。
