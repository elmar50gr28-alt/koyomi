# 四柱推命の要約と詳細の整合性

上部の命式要約と五行グラフは、四柱推命の詳細鑑定を生成した計算結果から表示する。旧来の簡易計算による身強弱・用神・五行量を、詳細鑑定と混在させない。

- `buildBaziReading` が詳細文と同じ統合データのアダプター・事実抽出を経て `calculationSummary` を返す。
- `summary-ui.js` はその値を表示するだけで、占術計算や点数の変更を行わない。
- 用神が確定していると誤解されないよう「用神候補」「補助候補」と表示する。五行以外の格局IDは候補欄へ表示しない。
- 中和は有効な判定であり、判定保留と区別する。
- 出生時刻不明の場合はその制約を明示し、仮置き時刻の補正値を実際の出生時刻のように表示しない。
- 数値の欠落を0で代用せず「—」と表示する。実際の0は0.0と表示する。
- 新規の表示モジュールもサービスワーカーの事前保存対象とし、完全オフラインを維持する。

回帰例は1990年6月15日、出生時刻不明、東京都千代田区の検証用プロフィール。従来は上部「中和・土」、詳細「身弱・水」だった。修正後は同じ計算元による「身弱・用神候補 水」と五行量を表示する。

`tests/bazi-summary-consistency.test.mjs` で矛盾の再現、30日×出生時刻既知・不明、計算結果の非変更、中和、欠落値、オフラインの保存対象を検証する。複数占術の総合点と人生グラフは別の表示モデルであり、今回の変更対象には含めない。
