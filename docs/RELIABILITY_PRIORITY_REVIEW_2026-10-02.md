## 再計算の結果

`npm run evaluate:earthquake-shortterm`で現行カタログから再生成。全12条件で既存のdevelopmentPassed基準を満たさなかった。
これは短期活動モデルの開発評価であり、全予測エンジン・火山モデルの成績を表すものではない。

M6以上・7日、2013–2014確認区間の例（地震件数ではなくセル×評価窓の件数）:

- 真陽性47、偽陽性8,989、偽陰性186、真陰性76,152。
- 適合率0.520%、再現率20.172%、見逃し率79.828%、偽陽性率10.558%。
- 同じ9,036窓を一様ランダムに選ぶ基準の期待的中数24.661、期待適合率0.273%、期待再現率10.584%。
- ランダム期待値より的中数は多いが、背景確率モデルに対する情報利得は-0.0007303、Brier改善は-0.000001163。採用基準は未達。

ランダム基準は同じ警報件数の解析的期待値であり、乱数試行の有意差検定ではない。重複窓・空間依存の信頼区間は未実装。既存の `realHoldoutExecuted:false` を維持し、研究結果を発生確率や警報の公開根拠へ昇格させない。
