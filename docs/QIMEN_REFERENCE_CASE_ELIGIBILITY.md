# 奇門遁甲・日時付き参照盤候補の適格性監査

確認日: 2026-10-05。確認者: Codex（公開翻刻およびCADAL影印の目視確認。人間の採否確認は未実施）。

## 対象と位置

[程道生『遁甲演義（四庫全書本）』巻二](https://zh.wikisource.org/wiki/遁甲演義_(四庫全書本)/卷2)の「竒門吉格」から、日時・局数・配置の記載を持つ次の例を確認した。公開翻刻の章見出しと例の識別語を位置情報とする。下記のCADAL影印で該当箇所を追加確認したが、翻刻の底本と同一版であるとは認定しない。

これは原文の配置情報の要約で、現行計算が出した期待値ではない。吉凶の効能は検証していない。「乙庚之日」「丙辛之日」は日干の組を示す記載として扱い、特定の西暦日を補わない。翻刻の甲巳という表記は残し、影印の甲己と証拠を分離する。影印に基づく入力候補は甲または己の日干であり、日支を補わない。

飛鳥跌穴の例は画像11末尾から12冒頭へ続く。画像12右端の例の入力に甲己があり、同じ画像の次の例にも甲己が見える。これはCADAL影印での読取り結果であり、翻刻の底本の誤字か入力時の誤りかは判定しない。候補の字形疑義は画像側で絞り込めたが、正式な資料・規則の承認には昇格させない。

## 適格性の判定

3例とも、現在の `referenceCases` の登録条件を満たす日時付き全盤としては採用保留。年・暦日、地点と時区、時刻基準、日境界、現行の拆補法／固定式との対応、全九宮が揃わない。局数が明記されていても、日時からその局を得る規則の証明にはならない。

部分配置の例は、原本照合後に「局数と干支を直接指定した配置試験」の候補になり得る。その試験を、節入り・日柱・時柱を含む盤生成全体の検証と数えない。推定の西暦日や東京の標準時を加えて、古典の実例に見せない。

## 次の照合

1. 人間の確認者が上記画像番号・版心位置・甲己の読取りを確認し、確認日と判断を記録する。翻刻の底本との版の対応は別途調べる。
2. 日時入力の検証用資料は、暦法・年月日・場所・時刻基準が明記された別の全盤例を探す。欠落事項は資料側の記載と推定を分離する。
3. 原本から全九宮を確認できた場合に限り、部分配置の期待値候補を別ファイルへ登録して既存盤と比較する。
