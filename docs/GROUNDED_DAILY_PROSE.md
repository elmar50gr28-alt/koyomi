# 日次鑑定の具体的な読み解き（3.11）

20主題それぞれに3段落、計60の読み解きを追加。単語の置換でなく、返信待ちの想像、引き継ぎ、家事の見えない準備、購入後の手入れなど、場面と判断の理由を文章として用意する。未入力の事情や相手の内心は事実とせず、条件のある場面として伝える。

主題選択では、相談分野と鑑定強度に合う候補のうち、算出されたテーマに対応する未使用の行動を優先する。これまでは直近の重複ペナルティがテーマ適合を上回り、未使用の適合行動が残っていても別主題へ移る場合があった。

対応する有限の行動が尽きた後は、同じ相談分野の他の行動を選べる。その場合に算出テーマを根拠として表示しない既存の規則も維持する。主題に固定し続けて反復を増やすことも、変化のために占術の根拠を捏造することも避ける。

点数や出生図の計算式は変更せず、既存の算出結果から文章を選ぶアルゴリズムを修正する。日付・人物・履歴が同じなら再現し、乱数や外部通信は使わない。キャッシュ版を更新する。

追加検証は5分野×3強度×30日＝450件。全文重複率0%、行動IDの再使用率0〜20%。全文一致の指標であり、意味や段落が毎日すべて異なることを示すものではない。根拠優先・使い切った後の表示・相談分野・強度制約・再現性も検証し、既存7050件の日次連続鑑定を併用する。これらは文章と算出結果の整合性の検証であり、的中率の実証ではない。
