# 本鑑定の日送り

本鑑定結果の上に「前日」「翌日」「今日に戻る」を表示する。中央の日付を押すと日付指定を開ける。人物と問診は現在の入力を使い、開いている占術と読んでいる位置を保つ。

日付変更は既存の鑑定生成経路を使う。連打は最後に選んだ日を優先し、更新中・失敗時は日付の異なる結果を表示しない。失敗後は再試行、または別の日付を選べる。

表示上の「今日」「今夜」などは選択日に合わせる。保存済みの鑑定原文は変更せず、人物台帳へ記録する際にも選択日の表現を使う。出生図は固定し、運期・流年・月運表は選択日を基準に計算する。日付生成時刻は既存の今日・カレンダー経路と同じローカル午前0時とし、日送りの往復で同日の点数が変わることを防ぐ。

追加通信・外部ライブラリは使わず、操作部の資産もオフラインキャッシュに含める。

検証: `tests/reading-date-navigation.test.mjs`（暦境界、夏時間、連打、再試行、日付表現、出生図不変・選択年の運期）、既存の日次鑑定・モバイル・全体回帰テスト。画面では日送り・日付指定・翌年・今日への往復・占術の開閉維持を確認する。
