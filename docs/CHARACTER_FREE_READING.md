## 口調の統一と着眼点の拡充（2026-10-21）

- 「〜わよ」「〜なのよ」「〜なさい」「〜ちょうだい」などの演じる語尾を、日次・11占術・詳しい資料・暦の補足から外す。温かい呼びかけと具体的な助言を基本にする。
- やさしく／はっきりの違いは、結論の順序や注意の伝え方で表す。人物像や性別を連想させる語尾で区別しない。
- 丁寧な文を特徴的な語尾へ変えていた `conversationalize` は互換 API を残して原文を返す。表示時の一括置換は行わず、相談文・名前・計算値を加工しない。
- 日次の着眼点を20主題×3方向の60種類へ拡充。引き継ぎ、伝える順番、決め直せる範囲などを、その日の主題に対応させる。直近30日の使用回数と昨日の着眼点から選び、単なる日替わり乱数にはしない。
- 着眼点の追加で点数・鑑定強度・占術根拠・行動選択を変えない。旧履歴の識別子も読み続ける。履歴に残る3番目の着眼点も、翌日の比較で正しく名前を表示する。

`daily-discovery` で720件の連続鑑定と60種類への到達、昨日との重複抑制、計算結果の不変性を検証。`all-reading-copy` では実際の生成文を対象に、通常・代替・資料・別画面・奇門の語尾を検査する。活用が崩れた文章も回帰検査に含める。
