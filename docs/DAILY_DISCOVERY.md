# 毎日の着眼点と振り返り（3.12）

20の主題に各2種類、合計40の着眼点を用意する。同じ休息の主題でも「気がかりの置き場」と「休める環境」を分けて問いかけ、対応する夜の振り返りも用意する。質問は自己観察のためのもので、未入力の事情や出来事を事実として補わない。

着眼点は直近30日の使用回数と使用日から選ぶ。同じ主題が連続した場合は、前日と異なる着眼点を使う。履歴に保存するのは選ばれた着眼点のIDだけで、行動を実行した・成功したという情報にはしない。

前日も同じ主題で、有効な着眼点IDが残っている場合は、本文内で昨日と今日の着眼点を具体的に示す。強度が変わった場合の「流れの変化」とは区別し、角度だけの変更を吉凶の変化として表示しない。以前の履歴に着眼点がなくても利用でき、別の人物や未来の日付、間の空いた履歴を昨日として扱わない。セクション数を増やさず、短い鑑定では着眼点の問いが本文に残る。

既存の解釈段落・語り口・構成・具体策を再利用する。学習と振り返りには慎重な日の行動を各6件追加し、候補の不足による反復を減らす。以前からある行動IDは変えない。完全オフラインで動作し、文章キャッシュ版と配信キャッシュ版を更新する。

検証は8分野×3強度×30日＝720件。40種類すべての到達、全文重複なし、行動IDの再使用率20%以内、同一主題の前日との着眼点変更を確認する。着眼点だけを変えても点数・強度・助言・注意・場面・構成が変わらないこと、夜の問いとの対応、再起動とキャッシュ、旧履歴の互換性も確認する。既存の日次連続・意味反復テストと併用し、全文一致だけで意味の変化を評価しない。
