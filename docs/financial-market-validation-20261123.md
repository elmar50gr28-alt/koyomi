# こよみ金融占星術：実相場との過去検証（2026-11-23）

## 結論

**現行モデル（`koyomi-market-symbolic-direction-v1`）の一貫した予測優位性は確認できない。**
少なくとも、実証済み予測・利益が期待できる予測とは表示してはいけない。

ルールを過去データに合わせて変更せず、主要アスペクト・逆行から出る「上昇／下落／方向感なし」を実際の終値と照合した。

**日経平均の14日だけは常時上昇より高い**が、この違いだけで予測力を実証したとは言えない。市場・時期・予測期間を選ぶことで見かけ上の結果が変化する。複数期間で一貫して優位な結果は出ていない。

## 検証方法

- 評価対象は暦日1・7・14日。起点となる取引日の終値から、指定日以降の最初の取引日の終値までの符号を照合する。指定日から5暦日を超えて後ろにずれたケースは除外。
- 起点を過去の評価期間終了前に重複させない。独立に近いサンプルを優先するが、市況は相関を持つため厳密な統計的独立を保証しない。
- 上昇・下落を言い切った占断のみ的中率の分母に含める。方向感なし、実値変化0、未確定は除外して別途件数を管理する。
- ベースラインは**まったく同じ選択された評価日**に「常に上昇」と予想する手法。データの上昇傾向との比較を行う。
- 占断の計算は天体位置と既存の固定ルールのみを使用。値動きの結果を判定関数に渡さない。計算時刻は03:00 UTC（日本時間12:00）。
- 計算精度・出典の第三者確認、手数料・スリッページ、売買可能性、統計的な信頼区間、未使用期間による前向き検証は未実施。
- 方向性の閾値・重みを今回の実相場データを見て最適化しない。

## 使用した実際の終値データ

- NASDAQ100：Yahoo Financeの`^NDX`日次終値を公開する第三者ミラー [Chief-rich/nasdaq100-data](https://github.com/Chief-rich/nasdaq100-data) の `data/ndx_daily/history.csv`。2026-11-23取得。データの品質は公式には保証されない。
- 日経平均：公開歴史CSV [it-ces/Datasets](https://github.com/it-ces/Datasets) の `Nikkei225.csv`。2008年から2018年までの過去資料。現行の日経平均最新値ではなく、品質の独立監査は未実施。
- 再配布制約を避けるため**原データはこよみのリポジトリに格納しない**。評価スクリプトが解析時に直接取得し、ログに集計値のみ記録する。利用者もFREDなどから入手したCSVを本人の端末内で読み込める。
- 参照できる公表系列：FRED [日経平均 NIKKEI225](https://fred.stlouisfed.org/series/NIKKEI225), [NASDAQ100](https://fred.stlouisfed.org/series/NASDAQ100), [ドル円 DEXJPUS](https://fred.stlouisfed.org/series/DEXJPUS)。日経平均には再配布に制限がある。
