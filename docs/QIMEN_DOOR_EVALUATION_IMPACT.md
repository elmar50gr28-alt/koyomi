# 奇門遁甲・門配置候補の評価影響監査

確認日: 2026-10-05。本体未接続、資料・方式の採用未承認。

## 範囲と再現

実行: `node scripts/audit-qimen-door-evaluation-impact.mjs`。
[値使移動先の候補監査](QIMEN_DOOR_TARGET_CANDIDATE.md)の宮番号1〜9の順逆方式を使い、既存qmdjChart・qmdjScorePalace・qmdjEvaluateをVMで比較する。変更するのはコピー内の値使移動先1式だけ。寄宮は5→2の暫定方針を維持する。

陰陽遁2種×9局×60時干支の1080通り、目的general（総合）を対象とする。月支は子、日干は甲へ固定し、西暦日時は与えない。日干と時干支の組が実暦で成立するかは検証しない。月令・五不遇時等の背景条件を固定した感度分析であり、現実の1080日時・古典の評価正解・成功確率ではない。

## 結果

| 比較項目 | 変わった入力数 |
| --- | ---: |
| 最良方位の宮番号 | 645 |
| 総合点 | 785 |
| 九宮の門迫フラグの並び | 798 |
| 伏吟フラグ | 46 |
| 反吟フラグ | 176 |

総合点の絶対差は最大28。候補の総合点が全1080通りで有限かつ0〜100に収まることを確認した。最良方位は現在のソート結果の第1位を比較するため、同点順位の影響を含み、「唯一の最良方位が変わった」件数とは扱わない。

例: 人工入力の陽遁1局・乙丑時（番号1）では、最良方位が東・78点から南西・74点へ変わる。これは資料の実例や利用者への推奨ではなく、固定背景条件での実装出力比較である。

## 本体接続前の確認条件

門配置の変更は方位だけでなく、注意表示の門迫・伏吟/反吟と鑑定文に使われる評価へ波及する。次は実日時と時刻基準を与え、月令・日干・目的を変えた比較、同点方位の区別、保存済み鑑定の再表示と新規計算の区別を検証する。

中宮到達後の寄宮の典拠確認と人間の採否判断は別途必要。今回の点数差を根拠に候補を正解・高精度と承認せず、評価係数も変更しない。実アプリ・保存形式・資料台帳・安全ルールは保持する。
