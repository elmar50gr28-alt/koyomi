# 銘柄名・証券コードによる鑑定 v1

## 機能

- stock-reading.html で日本株の証券コード（英字を含む4文字）または日本語企業名を検索する。
- 初回オフラインで使える主要83銘柄を同梱。接続があれば第三者がJPX公開情報を加工した2026-05-31の約3,900銘柄一覧をユーザーの端末内にダウンロード・キャッシュする。公開一覧は古い可能性があり、現在の上場状況はJPXで確認する。
- 不明なコードに架空の会社名を割り当てない。利用者自身がコードと正式名を保存できる。
- 企業の上場日または設立日を入力した場合に限り、その日付の太陽・木星・土星と、未来の火星・木星・土星・天王星の角度関係から象徴的な90日鑑定を行う。
- 時刻・場所が不明なため、企業個別のハウス・ASC・月を使用しない。日付の計算はUTC正午の仮時刻。
- 企業の基準日がない場合、企業固有の占星術はせず、市場全体に共通する占星術の象徴を表示することを明記する。
- 1〜30日・31〜60日・61〜90日を7日間隔の観測点で計算。価格統計に基づく株価の方向予測ではない。
- 数秘術は付番された証券コードのみを別計算。数字/英字の意味が業績を左右するという根拠はない。
- タロットは既存の78枚を暗号学的乱数で抽選し、既存のtarot.jsを再利用する。
- 実価格は銘柄ごとに読み込んだ手動CSVがある場合だけ、実際に観測された価格リスクを別枠に表示する。

## 正確性と制約

- 個別企業の最新株価、設立日、上場日、決算は外部APIで自動取得していない。正規のデータ提供条件が判明するまで架空の価格を出さない。
- 企業名・銘柄マスターは参考用。上場廃止や社名変更はJPX公式の情報で確認する。
- 占いの吉凶は株価騰落・暴落時期・収益率を予測できると実証されたものではない。売買シグナルには利用しない。
- 銘柄検索語・選択銘柄・企業の日付・価格CSVは外部送信せず、個人端末のみに保存する。
