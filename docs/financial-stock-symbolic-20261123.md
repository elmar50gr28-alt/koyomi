# 銘柄名・証券コードによる鑑定 v1

## 機能

- stock-reading.html で日本株の証券コード（英字を含む4文字）または日本語企業名を検索する。
- 初回オフラインで使える主要83銘柄を同梱。接続があれば第三者がJPX公開情報を加工した2026-05-31の約3,900銘柄一覧をユーザーの端末内にダウンロード・キャッシュする。公開一覧は古い可能性があり、現在の上場状況はJPXで確認する。
- 不明なコードに架空の会社名を割り当てない。利用者自身がコードと正式名を保存できる。
- 企業の上場日または設立日を入力した場合に限り、その日付の太陽・木星・土星と、未来の火星・木星・土星・天王星の角度関係から象徴的な90日鑑定を行う。
- 時刻・場所が不明なため、企業個別のハウス・ASC・月を使用しない。日付の計算はUTC正午の仮時刻。
- **修正v2**：企業基準日がない場合は、同一の日付・市場天体象徴を全銘柄の主鑑定へ再利用していた問題を解消。個別の主表示は、コード基礎数・桁位置の加重数・鑑定基準日の数・区間番号から得る銘柄コード数秘周期に変更。共通の市場星占いは必ず別表示にする。
- 企業の設立日・上場日がないとき、企業固有の占星術は計算していないことを入力欄・鑑定画面で明示する。
- 1〜30日・31〜60日・61〜90日を7日間隔の観測点で計算。価格統計に基づく株価の方向予測ではない。
- 数秘術は付番された証券コードのみを別計算。数字/英字の意味が業績を左右するという根拠はない。
- タロットは既存の78枚を暗号学的乱数で抽選し、既存のtarot.jsを再利用する。
- 実価格は銘柄ごとに読み込んだ手動CSVがある場合だけ、実際に観測された価格リスクを別枠に表示する。

## 正確性と制約

- 個別企業の最新株価、設立日、上場日、決算は外部APIで自動取得していない。正規のデータ提供条件が判明するまで架空の価格を出さない。
- 企業名・銘柄マスターは参考用。上場廃止や社名変更はJPX公式の情報で確認する。
- 占いの吉凶は株価騰落・暴落時期・収益率を予測できると実証されたものではない。売買シグナルには利用しない。
- 銘柄検索語・選択銘柄・企業の日付・価格CSVは外部送信せず、個人端末のみに保存する。

## v2 同一鑑定になった問題の調査と反証

1. 原因：v1の数秘術はページ下部にしか表示されず、90日間の本体は企業基準日未登録だと `readFinancialSky → marketDaySignal` の結果が全銘柄で同じだった。銘柄コード・社名・業種は占術本体の入力になっていなかった。
2. 是正：コード基礎数（各桁・英字A=1〜Z=26の和を一桁還元）、位置重み数（左から1〜4倍して還元）、鑑定基準日の数字和、月区間0〜2を合算して還元する。**基準日は3区間に固定して周期だけを進める**ことで、期間1と3が偶然同じに戻る不自然な現象を防止。各期間で基礎数・今期の数・読み解き・式を明示する。
3. 検証：内蔵の主要83銘柄はコード基礎数・位置重み数の組合せが48種類（数秘の同値はあり得る）。いずれも3つの30日区間は異なる今期の数を持つことをテストする。トヨタ自動車7203と日本トムソン6480の同一日鑑定では、主表示が共通の星読みのコピーでないことを確認する。
4. 正確性の制約：同じ設立日・上場日を入力した場合、企業に対応する天体配置は数学的に同じになる。別々の企業の星回りと偽らない。付番されたコードによる数秘が異なることと、業績・将来の株価が異なることは無関係。**数秘によるバリエーションは予測精度の改善ではない**。時系列検証・実相場による統計的優位性は未実証。
5. UI改善：企業基準日入力欄を初期表示し、数秘のみと会社基準日占星術を画面見出しから区別する。共通天体象徴は独立欄で表示。PWAキャッシュをv2に更新する。
