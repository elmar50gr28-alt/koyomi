# 奇門遁甲の天文判定と時刻補正の分離案

作成日: 2026-10-03
対象main: 56932fe4e1c3a35aba03d4044fb0f5ee04d94f02
状態: implementation_policy（PR #426のマージ後、このPRで実装。古典ルールの approved を意味しない）

## 問題と根拠

現行 `qmdjChart` は地方平均時・真太陽時への補正後の日時を、太陽黄経・節入りの天文計算にも渡している。2026年の監査では天文節入りに対する入力時刻上の切替が最大約44分移動した。結果と再現手順は [QIMEN_TERM_CHART_BOUNDARIES.md](QIMEN_TERM_CHART_BOUNDARIES.md) に記録する。

国立天文台の[暦要項の説明](https://eco.mtk.nao.ac.jp/koyomi/yoko/)は節気の時刻を太陽の視黄経が指定値に達する時刻とする。[二十四節気の用語解説](https://eco.mtk.nao.ac.jp/koyomi/faq/24sekki.html)も各節気を太陽視黄経で定義し、春分・秋分をその値に達する瞬間としている。確認日2026-10-03。

この天文定義から、経度補正や均時差をUTC瞬間へ加算して太陽を計算し直す操作は、時刻表示の換算ではなく別の瞬間の計算になると推論する。これはソフトウェアの時刻モデルの判断であり、国立天文台が奇門の流派・三元・符頭を認定したという意味ではない。

既存 `DECISIONS.md` の「流派を一つの正解へ統一しない」「根拠未確認の判断にはreviewStatusを付ける」と、[典拠・レビュー台帳の運用](QIMEN_SOURCE_REVIEW.md)を保持する。流派差の典拠は今回の天文資料だけでは確定しない。

## 提案する時刻の役割

同じ入力から、次の2つの日時を明示的に作る。

- astronomicalDate: 入力が表す実瞬間。選択したUTCオフセットによる壁時計表示を持たせても、getTime()は入力と一致する。
- clockDate: 現行の標準時・地方平均時・真太陽時の補正を適用した、日・時の判定用日時。補正量を別途保持する。

| 計算・表示 | 使用する基準 | 提案理由 |
| --- | --- | --- |
| 太陽黄経、節気名、節入り瞬間 | astronomicalDate | 指定された実瞬間の天文状態を計算する |
| 陰陽遁 | 実瞬間で得た節気名 | 天文節入りの切替を経度・均時差で移動させない |
| 固定式の三元 | astronomicalDate − 節入り実瞬間の経過時間 | 現行の5日・10日しきい値を同一の時刻軸で比較する |
| 拆補法の符頭・三元 | clockDateと選択した日境界 | 流派候補の既存の暦判定を保持する |
| 日柱・時柱・旬首・空亡・馬星 | clockDateと選択した日境界 | ユーザーが選択した補正の用途を維持する |
| 年柱・月柱の節入り判定 | astronomicalDate | 同じ盤内で太陽黄経を判定する実瞬間を一致させる |
| 局数 | 実瞬間の節気名と上記の三元 | 既存局数表を維持し、基準だけ明示する |
| 節入り時刻の表示 | 節入り実瞬間を選択UTCオフセットで表示 | 表示の換算で実瞬間を変えない |
| 補正後の日時の表示 | clockDateと補正量 | 判定基準の説明と切り分ける |

固定式の「5日・10日」は現行の24時間×5・10という実装上の経過時間を維持する案であり、古典での暦日解釈の承認ではない。拆補法の三元を天文実瞬間に統一する変更は含めない。

年柱・月柱は奇門の呼出だけで日時を分け、四柱推命・西洋占星術が使う共有関数の式を変更しない。選択オフセットの年・暦日を保持し、端末時区への依存を再導入しない。

## 実装する場合の範囲

既存の `src/shared/qimen-time-core.js` に2つの日時を返す小さな補助関数を設け、`app.html` はその接続と引数の選択だけ変更する。太陽エンジン、均時差の近似式、局数表、盤配置、評価係数は変更しない。

固定式の三元計算には実瞬間、拆補法には補正日時を明示的に渡す。現在の `qmdjYuan(d,term,...)` で異なる時刻軸を暗黙に比較しない。保存済み人物データや履歴を一括変換せず、未知フィールドを保持する。旧盤との違いは境界付近で起こり得るため、計算基準の説明と変更前後の監査結果を残す。

過去の最大約44分の移動は変更前の記録として保持する。現行挙動を固定している追加432組の試験は、新しい仕様の期待値へ明示的に更新する。過去の測定結果を新実装の正解盤として使わない。

## 実装後の確認条件

1. 2025〜2027年の72節気で、計算根の前後1秒と公表時刻の前後90秒を分けて検証する。
2. 2026年の3地点・3時刻方式・2方式で、同一実瞬間の節気・陰陽遁が一致する。時刻補正の有効性は日・時柱と符頭の境界例で別に確認する。
3. 固定式は実瞬間の節入りから5日・10日の前後で三元が切り替わる。拆補法の符頭・三元は補正日時の既存ロジックと一致する。
4. 日境界0時・23時、UTC+9以外のオフセット、年越し、異なる端末時区を対象にする。
5. 局数表と選択された三元の接続、九宮・地盤の要素数、フォールバック0件を確認する。盤の古典的正否は別の日時付き参照盤で審査する。
6. 奇門の標準時と他占術に意図しない変更がないことを関連テストで確認する。

このPRでは上記の分離方針を採用し、奇門の盤生成へ接続した。流派資料・参照盤・review-registerの承認状態は昇格させない。変更前の切替移動は監査文書に保持する。
