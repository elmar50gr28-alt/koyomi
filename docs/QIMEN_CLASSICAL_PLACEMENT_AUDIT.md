# 奇門遁甲・古典の部分配置と現行計算の照合

確認日: 2026-10-05。状態: needs_human_review。

## 対象と再現

[参照盤候補の適格性監査](QIMEN_REFERENCE_CASE_ELIGIBILITY.md)で目視確認したCADAL01053967巻二の3例を対象とする。画像3–5・11–12の入力と明記された部分配置だけを期待値とした。全九宮や日時付き全盤としての承認ではない。

再現: `node scripts/audit-qimen-classical-placement.mjs`。実行時のapp.htmlから既存のqmdjChartと配置用関数・定数を読み、VMで呼び出す。局数・陽遁・時干支を資料から直接与えるため、時刻補正・節入り・三元・日/時柱導出を監査用の入力へ置き換える。西暦日を作らず、raw/clockDateはnullとする。年/月柱と日干の仮値は無関係な評価メタデータ用であり、比較しない。画面・保存・実アプリの関数は変更しない。

時干支の六十干支番号は甲子を0として、乙酉21、辛卯27、辛未7。天沖の字形のみ実装の天冲へ正規化する。

12比較項目のうち11一致、1不一致。これは限定した配置情報の件数で、精度や完成率ではない。資料にない門・神・中宮寄宮等を期待値として補完しない。

## 不一致の切り分けと次工程

現行qmdjChartは値使の移動先を8宮の外周配列QMDJ_RING上で時刻差分だけ進めている。天遁の例の公開翻刻は値使開門の移動先を7宮と記す一方、この実装では6宮から1歩進めて1宮に開門が来る。これが1宮の生門との差に関係する可能性がある。推論であり、古典規則の正式採用や修正方針の決定ではない。

次は値使の移動を数宮の順逆で数える規則と外周の転盤を分離して典拠確認する。陰遁・六旬・甲時・中宮に当たる例も必要。1例だけに合うように現行式を変更せず、人間の採否確認と流派差の整理を経て修正範囲を決める。

監査スクリプトは不一致をJSONに出力する。不一致を隠すために期待値を現行出力へ合わせず、終了コード0を「古典と全項目一致」の意味に使わない。資料台帳・候補の承認状態、実アプリの計算・表示・保存・安全ルールは保持する。
