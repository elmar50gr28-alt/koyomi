# 日次鑑定の連続性検証（2026-10-05）

## 変更の範囲

日次コア・履歴コントローラ・総合鑑定への接続・オフラインキャッシュの版だけを変更した。既存20テーマと12構成、既存の行動・注意文のID、三層鑑定を保持する。金銭に9件、休息・健康管理に各3件の具体的行動を追加した。

日運の点数、既存の四柱テーマID、質問分野、長期運を入力として使う。主テーマの順位は適合度と履歴の明示的な加点で決め、日付のハッシュは同順位の文章部品選択にだけ使う。質問分野と低日運時の候補制限は重複抑制より優先する。これは既存計算結果の説明・行動提案を編集する規則であり、新しい占術の計算則ではない。

強度は日運45未満で守り、70以上で前進、それ以外で試行。長期運45未満・矛盾信号・入力確度0.5未満の場合は前進を試行へ抑える。確度の単位は0〜1。根拠のない時間帯・昨日の出来事・本人の性格は推測しない。

直近30暦日の同じ人物の記録だけを参照する。同日・未来・31日以上前の記録を除外し、未使用部品を優先、全候補使用後は最少使用・最も古い使用を優先する。物語のテーマ・場面・強度・構成の組合せも抑制する。保存済みv2の履歴は引き続き使い、キャッシュはコア版と入力条件で更新する。保存できない場合も生成は可能。ネットワーク・外部AI・追加ライブラリは不要。

## 批判的再検証と修正

- 部品を個別に避けても物語が再出現したため、組合せ単位の抑制を追加。その修正で構成の多様性が下がったため、同じ物語の回数を最優先にし、全体の構成使用回数も順位に含めた。
- 0点を50点へ置換する不具合、履歴の入力順依存、同日・未来の混入、別人物による履歴の押出し、質問や信号変更時の古いキャッシュを修正。
- 生の注意文が「急な悪化を我慢して様子見する」のように推奨にも読めたため、「ことは避けて」を明示。行動文の自動言い換えは行わず、既存の完成文を保持。振り返りの助詞と物語内のテーマ二重記載も修正。
- 総合鑑定で保存のみされていた日次文を表示へ接続。実際の表示関数を簡易DOMで実行し、従来鑑定保持、二重付加防止、非同期処理中の人物切替を検証。
- 医療や投資への確定助言、根拠のない時間帯の予測、昨日の方針の否定を避ける条件をテスト。一般の日本語の自然さやあらゆる意味矛盾を自動テストだけで証明するものではない。

不変の日運に対してテーマを無制限に入れ替えること、全分野の行動反復ゼロ、従来鑑定全文の反復ゼロは保証しない。時刻の追加判定も導入していない。

## 2026-10-06：相談切替と本文の整合性（v3.3）

実際の開始ボタンは人物・日付・出生情報だけで結果を再利用しており、同じ日に相談や設定を変えても古い画面へ戻る場合があった。また「具体的に見たいこと」の選択は、日次コアに渡されていなかった。

相談・具体的焦点・比較する選択肢・読み方・流派設定・口調・表示言語・姓名情報を含むリクエストキーを既存コントローラで生成し、実際の表示文と結果オブジェクトも比較して再利用するよう修正。計算中に相談や選択人物が変わった場合は、その入力を計算済みとして記録しない。失敗後に元の相談へ戻る場合、表示を消した場合、内部結果だけが置換された場合も再表示を検証する。失敗した日付指定の鑑定は、以前の結果や途中の結果を開かない。

具体的焦点を最優先にし、中立の「本質・性格」の場合は既存の質問解釈の分野、そのあと大分類を使う。自由文の解釈は既存キーワード規則を再利用するもので、あらゆる相談を理解するものではない。学習・創作などの焦点は既存の成長分野へつなぐ。金銭・健康の具体的焦点を選んだ場合も、対応する安全上の説明を保持する。行動177件の文章とIDは変更していない。
